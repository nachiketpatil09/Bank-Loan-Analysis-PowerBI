# 🏦 Bank Loan Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Bank Loan Analysis Dashboard built using Microsoft Power BI.

The dashboard analyzes loan applications, funded amounts, repayment performance, loan quality, and customer loan characteristics to provide a clear view of overall lending performance.

---

## 🎯 Business Objectives

The main objectives of this project are:

- Analyze overall loan application performance
- Track funded loan amounts
- Analyze received loan amounts
- Understand good vs bad loan performance
- Analyze loan status distribution
- Identify monthly loan application trends
- Analyze loan performance by state
- Analyze loan purpose and customer characteristics
- Provide an interactive dashboard for business analysis

---

## 📊 Key KPIs

The dashboard includes important banking KPIs such as:

- Total Loan Applications

- Total Amount Received
- Average Interest Rate
- Good Loan Applications
- Bad Loan Applications
- Good Loan Percentage
- Bad Loan Percentage

---

## 📈 Dashboard Analysis

The dashboard provides analysis of:

### Loan Applications
Analysis of the total number of loan applications and their monthly trends.

### Funded Amount
Analysis of the amount funded through different loan categories and customer segments.

### Loan Quality
Comparison of good loans and bad loans to understand overall loan performance.

### Loan Status
Analysis of loan status categories such as current, fully paid, charged off, and other statuses.

### Geographic Analysis
Analysis of loan activity across different states.

### Loan Purpose
Analysis of loans based on different purposes and categories.
